# Precedência de fontes

1. Dados e decisões explícitas do usuário para o job atual.
2. Process Doc ativo: governa fases, dependências, gates, critérios de aceite e pacote default.
3. MASTER_EDITORIAL: governa PROBLEM/SOLUTION/ASSET, taxonomias, CTAs e campos de formulário.
4. Estado e evidências existentes no job.
5. Templates.

Conflito conhecido: o MASTER_EDITORIAL exemplifica 12 tipos de asset por problema, enquanto o Process Doc V02 define um pacote de produção com quantidades específicas por ciclo. A skill usa o Process Doc para o pacote da Fase 1 e usa o workbook para taxonomia/identidade dos assets. Valores explícitos do formulário substituem defaults, sem apagar rastreabilidade.
