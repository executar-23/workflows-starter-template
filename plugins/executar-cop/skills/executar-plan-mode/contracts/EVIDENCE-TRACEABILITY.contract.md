# EVIDENCE-TRACEABILITY · Contract

ID: CONTRACT-EVIDENCE-001  
Status: ACTIVE_WITHIN_SKILL  
Version: 1.0

## MUST

Para pesquisa, normas, documentação ou fatos:

1. MUST distinguir fonte primária, publicada, interna, observada e inferida.
2. MUST registrar URL ou path quando disponível.
3. MUST preservar divergências entre fontes.
4. MUST marcar inferência como inferência.
5. MUST evitar afirmação factual crítica sem suporte.
6. MUST separar "fonte encontrada" de "fonte validada".
7. MUST registrar lacunas quando suporte for insuficiente.

## Evidence record

```text
EVIDENCE_ID
CLAIM_ID
CLASS
SOURCE_TYPE
AUTHOR_OR_ORG
TITLE
DATE
URL_OR_PATH
LOCATOR
SUMMARY
CONFIDENCE
CONFLICT_STATUS
```

## Quality rule

Uma recomendação pode existir com classe `E · INFERIDO`, mas não pode ser apresentada como norma externa ou evidência primária.
