# Example · Research request → Plan

## Input

"Analise todos os documentos, complemente com web research, cruze evidências e produza contratos."

## Target output

### Objective

Construir corpus rastreável antes de qualquer contrato definitivo.

### Phase 01 · Source discovery

Output:
- inventory;
- authority map.

Gate:
- fontes de verdade identificadas.

### Phase 02 · Evidence research

Output:
- evidence ledger;
- claim register.

Gate:
- claims críticos rastreáveis.

### Phase 03 · Synthesis

Output:
- crosswalk;
- argument map.

Gate:
- convergências e divergências preservadas.

### Phase 04 · Draft contracts

Output:
- contratos DRAFT.

Gate:
- cada regra aponta para evidência.

### Stop

`PLAN_READY`
