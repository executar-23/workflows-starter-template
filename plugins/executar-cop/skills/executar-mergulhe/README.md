# Executar · Mergulhe

Habilidade proprietária da família Executar para transformar projetos, conteúdos e operações em estruturas navegáveis por ramos, compatíveis com **Executar · Árvore Visual** e Obsidian.

## Exemplo de pedido

```text
Use Executar · Mergulhe.
Organize este projeto em ramos, nós, dependências e portas.
Quero uma fila principal por data e ramos auxiliares por área.
Entregue também a versão Obsidian e o JSON da Árvore Visual.
```

## Saídas possíveis

- texto em ramos;
- diretório Obsidian;
- JSON;
- HTML interativo;
- pacote completo em ZIP.
