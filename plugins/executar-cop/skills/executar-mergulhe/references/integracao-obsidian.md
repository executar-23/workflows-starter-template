# Integração Obsidian

## Estrutura de pasta

A pasta representa localização e agrupamento.

A propriedade representa relação operacional.

```yaml
---
id: NO-001
depende_de:
  - NO-000
desbloqueia:
  - NO-002
---
```

## Wikilinks

Criar somente para notas existentes.

Preferir:

```text
[[25-08/ROTAS|Rotas]]
```

Não depender de ligações profundas externas como mecanismo principal de navegação interna.
